# Backlog

Deferred-but-wanted work, tracked so nothing rots silently. The weekly
perf-trend job renders every open item below (with its age) into the
[perf-review](docs/perf-review.md) report; anything older than two weekly
cycles without progress is flagged there for a schedule / split / close
decision.

Conventions (what `cargo xtask perf report` parses):

- one item per line under `## Open`: `- [ ]` open, `- [x]` done
- short id in bold, then the description
- `Added YYYY-MM-DD.` at the end so age is computable

Close an item by checking its box; move it to Done when archiving.

- [x] **pathfinding** — Tier 3 of the map roadmap (docs/maps/map-design.md): `bw_core::path::Pathfinder` plus the walker plugin's `FollowPath` controller. The Pathfinder is A* over the 4-neighborhood with a Manhattan × min-cost heuristic (admissible and consistent on 4-way — the first expansion of a node is its optimum, so lazy heap duplicates are safe to skip), deterministic beyond fixed-point inputs via the pinned East/North/West/South neighbor order and a total `(f, then index)` tie-break — the blank-map diagonal route is pinned tile-for-tile, so either law drifting trips a test. The ADR 0004 contract in full: one scratchpad per map size (open heap + `g_score`/`came_from`/stamp/closed arrays), a generation counter instead of clears (queries are O(visited); the u32 wrap does one full clear), results into a caller-reused `Vec<Tile>`, and costs riding the map's derived cache — a step costs the entered tile's fixed-point cost, so stone is the cheaper walk and cost-0 tiles never open. Seven core tests pin straight routes, the tie-break golden, wall detours threading a gap at exactly the detour's length, fail-closed refusals (unwalkable/out-of-bounds endpoints and disconnected goals return false with an empty buffer; `start == goal` is the trivial `[start]`), meadow routes valid and byte-repeatable, and reused-scratch == fresh across 30 seeded queries (the sim-grid precedent); `steady_path_alloc.rs` drives 300 alternating queries with interleaved refusals at **0 blocks** after warm-up. `FollowPath` owns the remaining tile list and writes input per tick under `MoveTarget`'s law — extracted into a shared `steer_toward` both controllers now read (turn-in-place past a quarter-turn, cruise at `MOVE_TO_SPEED`, waypoints releasing at `FOLLOW_ARRIVE` 0.30 of each tile center, the route's own start tile releasing on the first tick); arrived routes hold inert — no `Commands` in `FixedUpdate`; plugin tests pin the L-route walk-and-hold and waypoint release (mid-route spawn, empty route). Map-gallery scenes run recorded corner-to-corner queries: connected scenes must connect, and any route found stays walkable and 4-adjacent (the archipelago's islands may legitimately refuse). Gates green; deps stay 77; walker-gallery artifact +5 KB inside budget. Next map tier: the live map viewer — pan, walkers on generated maps, A*-routed sends. Added 2026-09-23. Done 2026-09-23.
