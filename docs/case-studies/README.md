# Case studies

Short, evidence-backed write-ups of measured performance changes, kept so
future design choices can reference concrete numbers from *this* project
instead of general claims. Each study names the commits that produced the
data, the numbers before and after (regressions included), and the
commands to reproduce.

Conventions: numbered `NNNN-slug.md`, newest last, never edited after
committing — corrections get a new study or an ADR.
